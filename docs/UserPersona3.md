# Persona 3: Fulton Brenner - The First-Time Visitor

## Characteristics

- **Tech Comfort**: High - a young adult who frequently engages with all forms of technology. 
- **Goals**: 
    - Quickly browse lodge information, room pricing, and nearby island attractions without creating an account.
    - Learn about the lodge before deciding whether to make a reservation.
    - Create an account quickly and easily when ready to book a stay.
    - Securely access reservation information through an online account.
- **Frustrations**:
    - Being required to create an account before viewing basic information.
    - Confusing checkout processes and unclear pricing.
    - Slow-loading pages, broken forms, or inconsistent room information.
    - Complicated registration requirements and password rules.

## User Stories: 


1. As a first-time visitor, I want to explore the website without logging in so that I can quickly decide whether Moffat Bay Lodge meets my vacation needs.
2. As a first-time visitor, I want clear information about the lodge, room options, pricing, and nearby attractions so that I can plan my vacation.
3. As a first-time visitor, I want to create an account quickly and easily so that I can book a reservation without unnecessary delays.
4. As a first-time visitor, I want to receive confirmation after registering and submitting a reservation so that I know my information was saved successfully.
5. As a first-time visitor, I want to securely log in to my account so that I can access and manage my reservation information.


# Top Priority:
