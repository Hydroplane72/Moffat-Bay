# Pacific Northwest Image Sources

The website uses remote, compressed image URLs so the repository stays small while the browser receives optimized image files. Unsplash URLs request JPG output at 72% quality with a maximum width of 1200 or 1600 pixels. Non-critical attraction images also use `loading="lazy"`.

## Accessibility

Every image added to the HTML includes descriptive `alt` text. The landing-page slideshow also respects the user's reduced-motion preference by displaying a single static image when reduced motion is enabled.
